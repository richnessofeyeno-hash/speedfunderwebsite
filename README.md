# SpeedFunders Website

## New rebuild
This repository is the clean rebuild of SpeedFunders. The previous `speedfunder` repository is kept as a backup.

## Locked implementation rules
BUILD → VERIFY → COMMIT → LOCK → CONTINUE

Locked content requirements:
- About: 5+ meaningful lines per major point.
- Services: 5+ meaningful lines per service.
- Process: 5+ meaningful lines per stage.
- Pricing: clear scope, deliverables and creator responsibilities.
- Backers Community: detailed creator-facing explanation and clear distinction from full campaign management.
- Contact: brief pricing evaluation below the form.
- Header logo: small circular SpeedFunders logo.
- Footer logo: small circular SpeedFunders logo.
- Home hero: large premium SpeedFunders brand artwork; do not replace it with the small circular logo.
- Home hero headline uses the white + bright-green color treatment from the approved visual reference.

## Important portfolio status
The portfolio data file contains the campaign records prepared previously. The portfolio is NOT considered production-locked until each campaign has a verified Kickstarter image mapped to the exact campaign record and URL. Do not invent or guess image URLs.
